## 🧪 Tasks Included

### Task 1️⃣ – Intersection of Two Lists
- Finds common elements between two lists
- Removes duplicates

### Task 2️⃣ – Group Words by Length
- Groups words based on their length
- Returns a dictionary

### Task 3️⃣ – Merge Two Sorted Lists
- Merges two already sorted lists
- Does not use built-in `sort()`

### Task 4️⃣ – Longest Consecutive Sequence
- Finds the length of the longest consecutive numbers sequence
- Works even if the list is not sorted

### Task 5️⃣ – Diagonal Sum of Matrix
- Calculates the sum of both diagonals of a square matrix
- Counts the center element only once
